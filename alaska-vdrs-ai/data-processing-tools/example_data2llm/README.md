Scripts go here until further notice.

### data2llm
Scripts that take input PDF/ePUBs/TXT files and clean up their raw text with the help of the OpenAI API, and generate JSON files of the input content in 4000-5000 token chunks with a short summary/keyword list on top. 

### LoRAMaker
Generates question-answer pairs with the OpenAI API based on JSON input files. The resulting question-answer pairs can then be used for training or as a dataset for a large language model.
