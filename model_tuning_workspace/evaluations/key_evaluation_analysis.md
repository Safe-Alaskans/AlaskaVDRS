# Evaluation analysis

## Overview
Below is a list of key areas for how narratives are to be evaluated.

It is **vital** that this list is:
1. Valid
2. Covers the most important aspects of the narratives

This is because **once confirmed, the model will be fine-tuned to adhere to each of these guidelines**.

## Key evaluation areas

### Key info to include:
- Parties involved
  - Number of parties involved  
  - Relationship between parties
  - Sex, age, race for parties
  - If multiple S or V, differentiate with S1, S2, V1, V2...
- Weapons
  - Type of weapon
  - Ownership of weapon relative to S/V
- Location type (e.g. house, street, park)
  - Explain if location belongs to someone
  - Should go more in depth if possible 
    - e.g. "Inside S1's house ... Happened in S1's lounge"
- Circumstance(s) must be included (e.g. argument, robbery, self-defence)
- Injuries
  - Number of injuries
  - Body parts injured
  - Severity of injuries
- Witnesses (if any)
- If incident involved V being found
  - Who found V
  - Alive or deceased
- Physical/mental health issue only to be mentioned if relevant to incident

### Key info to exclude:
- No PII should be in narratives, which includes
  - Names
  - DOBs
  - Addresses
  - Organisation names (businesses, hospitals, LE agencies...)
- No dates or recognisable days included (e.g. Monday, 1st of January, Christmas Day)
- If weapons or drugs are discovered, but not relevant to the incident, the narrative should not include them
- No in-depth toxicology reports or autopsy reports, just a concise mention if necessary to provide context
- Irrelevant circumstances shouldn't be included

### Additional info
- No abbreviations to be used other than V, S, V/S

### Writing style

- High-level picture painting using broad strokes
- Events must be in chronological order
- No filler, stay concise & informative 
- No copying word for word from source docs
